Artwork Refresher

Looks for new posters, backdrops, logos and thumbnails from public sources, on a schedule or for one item from its card menu (⋮ → Refresh artwork). Genres, studios and collections get a mosaic made from artwork the server already has. Nothing is installed or changed until you save, and a dry run only reports what it would do.

Run

"Run now" ignores the time window. The scheduled task (Dashboard → Scheduled Tasks → Refresh artwork) wakes up every 30 minutes and only works inside the window and no more often than the interval.

What to refresh

Replacing artwork may overwrite images you picked by hand or that other Jellyfin image providers fetched.

Rotating images

For each image type the plugin keeps a pool of candidate images per item (from the enabled sources) and varies what is shown. Per page load: every reload of the page shows another image of the pool; the image stored in Jellyfin is not changed (needs the client script below; it works on the standard Home rows such as Recently added, on detail pages and on any custom Home that shows ordinary item images). Once a day: the stored image changes during the scheduled run. A random image that was not shown yet is chosen, and none repeats until the pool is used up.
Daily rotation replaces the stored image of every unlocked item of that type (like Replace mode), so try it with Dry run first. Locks, excluded libraries and book covers are still respected. Rotation never runs while Dry run is on.
A daily rotation only changes an image it wrote itself: if somebody replaces it afterwards, the rotation leaves it alone. Per page load, images are downloaded the first time they are shown and kept in the plugin's data folder up to the limit above (oldest deleted first). The run summary says how many images really changed by daily rotation.

Recently added and new items

This is what makes the "Recently added" rows of the standard Home and of custom Homes show real artwork soon after an item appears. The queue lives in memory: after a server restart the next scheduled run picks up items added in the last days.

Fill missing metadata (TMDb)

Looks at movies, series, episodes and people with empty fields and fills only the empty ones from TMDb, by the TMDb or IMDb id the item already has (no name guessing). Existing values and fields locked in Jellyfin are never changed. Needs TMDb enabled with a key. Books, comics and magazines are never touched. Dry run lists what would be filled.
None ticked = all fields. The text uses the first preferred language (or the server metadata language); when TMDb has no text in that language the field stays empty.
Book libraries that may be filled (opt-in; TMDb has no book data, so this only matters for future sources)

Libraries and protection

Excluded libraries are never touched. If you include some libraries, only those are refreshed (genres, studios and collections are not tied to a library).
Included (none ticked = all)
Excluded
Book covers are protected by default so they stay what a local thumbnail plugin (for example Auto Thumbnails) made from the file.

Image locks

Locks on a library or an item stop this plugin from changing the chosen image type (or all). Add them from here; the id is in the item's URL.

Shared images (genres, studios, collections, Home)

A genre or studio has one image for everybody, so its mosaic only uses content that is safe for every user, as you define it here. The plugin does not read the private rules of other plugins (Kids, Mature): list their libraries and tags here.
Sensitive libraries (never in a shared image)
Home images (GET ArtworkRefresher/Home/Sections and /Home/{key}/Image) are built per user from what that user can see; for non-administrators the rules above apply too.

Sources
