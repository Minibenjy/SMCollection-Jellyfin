Kids Mode

Kids Mode is a per-account allow-list: while it is on, the account sees only the content added to kids (and the libraries holding it), nothing else. There is a global list an administrator curates and, on top of it, each account can add or remove items for itself (an override). All of it is durable and re-applied at startup and after every scan.

Comportamiento

Visible tag applied to content on the global list. Defaults to kids.
